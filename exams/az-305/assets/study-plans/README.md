# AZ-305 Study Plans

Dated plans in this folder are personal and ignored by Git. Build them with the
[build-sprint-plan](../../../../.github/skills/build-sprint-plan/SKILL.md) skill
from the current AZ-305 outline in `../../exam.md`, the coverage audit, an exam
date, available daily time, and evidence in `../progress.md`.

Allocation is coverage-first under the
[progress-tracking contract](../../../../.github/instructions/progress-tracking.instructions.md);
weak topics get remediation slots, never all of the plan. When no baseline
exists, begin with a mixed diagnostic across all four domains.

Name plans `study-plan-YYYY-MM-DD-to-YYYY-MM-DD.md`. Treat dated files as
snapshots: create a new dated file for a major revision (new exam date,
post-mock reprioritization) with a short change note at the top.
