# GH-300 - GitHub Copilot

Exam config for the GH-300 study agent. Read this first when GH-300 is active.

## Domains (skills measured as of August 7, 2026)

1. **Use GitHub Copilot responsibly** (D1) - 15-20%
2. **Use GitHub Copilot features** (D2) - 25-30%
3. **Understand GitHub Copilot data and architecture** (D3) - 10-15%
4. **Apply prompt engineering and context crafting** (D4) - 10-15%
5. **Improve developer productivity with GitHub Copilot** (D5) - 10-15%
6. **Configure privacy, content exclusions, and safeguards** (D6) - 10-15%

The Microsoft Learn skills-at-a-glance list currently repeats a second
"GitHub Copilot features (25-30%)" line, but the detailed outline contains only
the six unique domains above. Do not treat the duplicate line as a seventh
domain.
