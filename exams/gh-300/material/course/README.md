# GH-300 Course Map

Use this sequence to build notes while completing the official learning paths.

| Domain | Focus |
| --- | --- |
| D1 | Responsible AI risks, harms, mitigation, validation, and human oversight |
| D2 | IDE, CLI, agent mode, Copilot Edits, Model Context Protocol (MCP), code review, Spaces, Spark, instructions, policies, audit logs, and subscriptions |
| D3 | Data flow, prompt construction, proxy filtering, post-processing, suggestion lifecycle, and large language model limitations |
| D4 | Context crafting, zero-shot and few-shot prompting, prompt structure, chat history, and performance |
| D5 | Generation, refactoring, documentation, modernization, tests, edge cases, security, and performance |
| D6 | Privacy settings, content exclusions, output ownership, public-code matching, and troubleshooting |

Official sequence:

1. [Fundamentals Part 1](https://learn.microsoft.com/en-us/training/paths/copilot/)
2. [Fundamentals Part 2](https://learn.microsoft.com/en-us/training/paths/gh-copilot-2/)
3. [GH-300 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300)
