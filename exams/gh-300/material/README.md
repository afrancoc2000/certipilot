# GH-300 Study Material

Start with the official resources in [exam.md](../exam.md). Local notes should
be organized by domain under `course/` and record the source URL plus the date
checked, because GitHub Copilot features and plans change frequently.

Suggested layout:

```text
material/
├── course/       # Original notes by D1-D6
├── github-docs/  # Summaries, not copied documentation
├── resources.md  # Curated official and internal training links
└── test-exams/   # Practice captures and question banks
```

See [resources.md](resources.md) for the internal GH-300 bootcamp, reference
guide, and official preparation links. Until local material is added, the
tutor generates original questions from Microsoft Learn and GitHub Docs and
cites the first-party page used to grade.
