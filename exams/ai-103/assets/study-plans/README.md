# AI-103 Study Plans

Dated plans in this folder are personal and ignored by Git. Build them from the
current AI-103 outline in `../../exam.md`, an exam date, available daily time,
and evidence in `../progress.md`.

When no baseline exists, begin with a mixed diagnostic across all five domains,
weighted toward D2 (Implement generative AI and agentic solutions, 30-35%) and
D1 (Plan and manage an Azure AI solution, 25-30%).

Because AI-103 covers fast-changing services, re-read the official study guide
at the start of each sprint and note any outline change in `../progress.md`.
