# AI-500 Study Plans

Dated plans in this folder are personal and ignored by Git. Build them from the
current AI-500 outline in `../../exam.md`, an exam date, available daily time,
and evidence in `../progress.md`.

When no baseline exists, begin with a mixed diagnostic across all four domains,
weighted toward D2 (Develop multi-agent solutions in Azure, 30-35%).

Because AI-500 covers fast-changing services and frameworks, re-read the
official study guide at the start of each sprint and note any outline change
in `../progress.md`. Use the checked status in [exam.md](../../exam.md), rather
than assuming a release status.
