# AI-500 Study Material

Start with the official resources in [exam.md](../exam.md). Local notes should
be organized by domain under `course/` and record the source URL plus the date
checked — AI-500 is a beta exam over fast-moving services (Microsoft Foundry,
Microsoft Agent Framework, Model Context Protocol), so material ages quickly.

Suggested layout:

```text
material/
├── course/       # Original notes by D1-D4
├── cheat-sheets/ # Decision trees: orchestration patterns, memory tiers, auth flows
└── test-exams/   # Practice captures and question banks
```

No local question bank exists yet. Until material is added, the tutor generates
original questions from Microsoft Learn and the official framework
documentation, and cites the page used to grade.
