# GH-600 Study Material

Start with the official resources in [exam.md](../exam.md). Local notes should
be organized by domain under `course/` and record the source URL plus the date
checked, because GitHub agent features change frequently.

Suggested layout:

```text
material/
├── course/       # Original notes by D1-D6
├── github-docs/  # Summaries, not copied documentation
├── cheat-sheets/ # Decision trees: autonomy levels, memory tiers, MCP scoping
└── test-exams/   # Local-only practice results (never committed)
```

Only original study material is shared under the
[source contract](../../../.github/instructions/sources-and-citations.instructions.md);
third-party content is never committed. Personal practice results under
`test-exams/` and personal state under `../assets/` stay local, except for the
shared asset README templates.

The tutor always generates original questions from Microsoft Learn and GitHub
Docs and cites the first-party page used to grade, whether or not local notes
exist.
