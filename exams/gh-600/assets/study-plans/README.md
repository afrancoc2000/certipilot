# GH-600 Study Plans

Dated plans in this folder are personal and ignored by Git. Build them from the
current GH-600 outline in `../../exam.md`, an exam date, available daily time,
and evidence in `../progress.md`.

When no baseline exists, begin with a mixed diagnostic across all six domains,
weighted toward D2 (tool use and environment interaction, 20-25%).

Plan for hands-on practice: the exam may include interactive components, so
budget lab time configuring custom agents, MCP servers, and repository-scoped
agent runs alongside the reading blocks.
