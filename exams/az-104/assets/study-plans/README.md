# AZ-104 Study Plans

Dated plans in this folder are personal and ignored by Git. Build them with the
[build-sprint-plan](../../../../.github/skills/build-sprint-plan/SKILL.md) skill
from the current AZ-104 outline in `../../exam.md`, the coverage audit, an exam
date, available daily time, and evidence in `../progress.md`.

Allocation is coverage-first under the
[progress-tracking contract](../../../../.github/instructions/progress-tracking.instructions.md).
When no baseline exists, begin with a mixed diagnostic across all five domains.
